# IBA Sukkur University RAG Assistant

Ask questions about IBA Sukkur University PDFs. Answers come from the most relevant chunks (FAISS) and are generated by Groq (`openai/gpt-oss-120b`), with the source documents shown.

## Project structure

```
app.py                       Streamlit chat app
ingest.py                    PDFs -> chunks -> embeddings -> FAISS index
requirements.txt
faiss_index/                 Output of ingest.py (index.faiss, index.pkl, manifest.json, metadata.json)
.streamlit/secrets.toml      Your Groq key (create from secrets.toml.example, never commit)
```

## 1. Build the index (Google Colab)

Cell 1: install
```
!pip install -q langchain langchain-community langchain-text-splitters langchain-huggingface faiss-cpu sentence-transformers pypdf gdown tqdm
```

Cell 2: download the Drive folder (about 50 files per folder limit with gdown)
```
import gdown
FOLDER_URL = "PASTE_YOUR_FOLDER_LINK_HERE"
gdown.download_folder(url=FOLDER_URL, output="IBA_Sukkur_University", quiet=False, use_cookies=False)
```

Cell 3: upload ingest.py to Colab (Files panel), then run
```
!python -m py_compile ingest.py && echo "Syntax OK" && python ingest.py
```

Cell 4: download the index
```
!zip -r faiss_index.zip faiss_index
from google.colab import files
files.download("faiss_index.zip")
```

Unzip `faiss_index.zip` into this project so `faiss_index/index.faiss` exists.

## 2. Run the app

```
pip install -r requirements.txt
mkdir -p .streamlit
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # then edit the key
streamlit run app.py
```

## Notes

- The embedding model in `app.py` and `ingest.py` must match (`all-MiniLM-L6-v2`).
- To use the 20B model, change `MODEL` in `app.py` to `openai/gpt-oss-20b`.
- Deploying to Streamlit Community Cloud: commit `faiss_index/`, and paste the key into App settings -> Secrets.
